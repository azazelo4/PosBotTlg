Какие колонки распознаются

Обязательные: Артикул, Цена. Также: Наименование, Тип/Категория, Металл/Материал, Проба, Вес, Размер, Вставки/Камни, Мин. цена, Цена за грамм, Остаток/Количество, Магазин, Производитель, Комментарий, Дата поступления, Себестоимость, Фото.

Тип изделия можно не указывать, если название начинается с него («Кольцо Классика»). Металл определяется по колонке «Металл» («Золото 585») или по пробе. Для товаров, которые уже есть в базе, обновляются только колонки, присутствующие в файле.

Фото. Положите таблицу и фото в один архив .zip (до 500 МБ). Фото к товару — по колонке «Фото» (имена файлов через запятую) или, если её нет, по имени файла: A100.jpg, A100_2.jpg — к артикулу A100. Фото добавляются только товарам, у которых их ещё нет, так что повторный импорт не создаёт дублей.
